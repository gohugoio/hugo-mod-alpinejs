# alpinejs

Hugo Module wrapper for the npm package [alpinejs](https://www.npmjs.com/package/alpinejs).

<!-- npmtohugomod:imports:begin -->
## Hugo import

Add this to your Hugo project's `hugo.toml`:

```toml
[module]
  [[module.imports]]
    path = "github.com/gohugoio/hugo-mod-alpinejs/alpinejs/v3"
```
